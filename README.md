# Tropik Chiclayo

Landing estática de Tropik: cremoladas de fruta artesanales y yogur natural frutado en Chiclayo, Perú.
Pedidos por WhatsApp (solo Chiclayo), mapa, reseñas y delivery desde 3 litros.

- HTML + CSS + JS sin build: `index.html`, `css/styles.css`, `js/main.js`, `assets/img/`.
- Vista local: `python -m http.server 8765` y abrir http://localhost:8765
- Pendiente de contenido real (marcado PROVISIONAL en el HTML): fotos propias con fondo transparente, datos del yogur, enlace de reseña de Google.
